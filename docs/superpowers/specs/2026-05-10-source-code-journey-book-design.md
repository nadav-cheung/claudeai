# 《跟着消息走：Claude Code 源码的旅程》 书籍设计

> 六卷本源码分析书，以《网络是怎么连接的》叙事风格，跟随一条消息穿越 Claude Code 系统。
> 读者从编程新手成长为能独立实现 Agent 框架的架构贡献者。

---

## 1. 书籍概述

| 项目 | 内容 |
|------|------|
| 书名 | 跟着消息走：Claude Code 源码的旅程 |
| 目标源码 | Claude Code CLI（当前仓库 src/ 目录） |
| 写作语言 | 中文，代码和术语保留英文 |
| 目标读者 | 编程新手（会写代码但没看过大型项目源码） |
| 风格 | 《网络是怎么连接的》纯叙事旅程风格 |
| 篇幅 | 六卷 66 章 + 6 附录，每章弹性篇幅（300-650 行），总计约 20-30 万字 |
| 文件位置 | `teaching/book/` 目录下 |

### 1.1 独特价值

1. **叙事驱动** — 不是按模块组织的技术手册，而是跟随消息穿越系统的旅程
2. **概念自然引入** — TypeScript 概念在需要时才出现，不前置堆砌
3. **场景化标题** — 每章标题是一个具体场景，不是抽象概念
4. **六阶段成长** — 卷零入门者→卷一追踪者→卷二理解者→卷三创造者→卷四架构师→卷五造物主
5. **编程新手友好** — 从"什么是源码"开始，不假设先验知识

### 1.2 写作原则

- **第二人称叙事**：用"你"和"你的消息"
- **场景钩子**：每章开头一句话交代消息当前在哪
- **生活类比**：消息像快递、工具像工具箱、权限像门卫
- **代码片段**：展示真实源码的关键部分，附带中文注释
- **下一站预告**：每章结尾预告消息即将进入的下一站
- **不用列表式教学**：避免"1.2.3 步骤"的教科书口吻

## 2. 六卷架构

### 2.1 卷与能力映射

| 卷 | 书名 | 叙事视角 | 读完能力 |
|---|------|---------|---------|

## 11. 实施策略

### 11.1 写作顺序

按卷顺序写，每卷内按章顺序写。原因：
- 叙事线是连续的，后面的章节依赖前面的设定
- TypeScript 概念逐步引入，不能跳步
- 卷五的组件是链式依赖（ch53→54→...→66）

### 11.2 每章写作流程

1. 确定本章的源码范围（哪些文件、哪些函数）
2. 阅读和理解源码
3. 确定要引入的 TS 概念
4. 写叙事段落
5. 插入代码片段和注释
6. 写下一站预告
7. 审校：确认源码引用准确

### 11.3 预计产出

- 卷零：每章 300 行起步（纯概念入门）
- 卷一~卷五：每章 400-650 行（含源码走读和代码实现）
- 全书 66 章 + 6 附录
- 总计约 20-30 万字
