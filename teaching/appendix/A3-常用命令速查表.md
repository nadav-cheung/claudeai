# A3 - 常用命令速查表

> **本章目标**：提供 Claude Code 开发中常用命令的快速参考，包括 CLI 命令、npm 脚本、git 工作流和调试命令。

---

## 1. 项目基础命令

### 1.1 安装与启动

```bash
# 安装依赖
npm install

# 使用 Bun 安装（更快）
bun install

# 开发模式启动
npm run dev

# 生产构建
npm run build

# 类型检查
npm run typecheck

# 代码检查
npm run lint
```

### 1.2 测试

```bash
# 运行所有测试
npm test

# 运行特定测试文件
npm test -- src/tools.test.ts

# 监视模式运行测试
npm run test:watch

# 生成覆盖率报告
npm run test:coverage
```

## 2. Claude Code CLI 命令

### 2.1 基本用法

```bash
# 启动 Claude Code
claude

# 指定工作目录
claude --cwd /path/to/project

# verbose 日志输出
claude --verbose

# 使用特定配置文件
claude --config /path/to/config.json
```

### 2.2 工具调用

```bash
# 使用特定工具
claude -t Read -- -f src/main.ts

# 列出所有可用工具
claude --list-tools

# 允许执行危险工具
claude --allow-tool Bash
```

### 2.3 MCP 服务器

```bash
# 启动内置 MCP 服务器
claude --mcp

# 指定 MCP 配置文件
claude --mcp-config /path/to/mcp.json

# 列出已连接的 MCP 服务器
claude --list-mcp-servers
```

### 2.4 Permission 相关

```bash
# 跳过权限检查
claude --dangerously-skip-permissions

# 指定权限模式
claude --permission-mode prompt

# 导出权限配置
claude --export-permissions /path/to/permissions.json
```

## 3. Git 工作流

### 3.1 分支管理

```bash
# 创建功能分支
git checkout -b feature/add-new-tool

# 创建 Bug 修复分支
git checkout -b fix/tool-permission-bug

# 创建文档分支
git checkout -b docs/update-api-docs

# 列出所有分支
git branch -a

# 删除已合并的分支
git branch -d feature/completed-feature
```

### 3.2 提交规范

```bash
# 提交规范格式
git commit -m "feat: add new tool implementation"
git commit -m "fix: resolve permission bypass issue"
git commit -m "docs: update API documentation"
git commit -m "refactor: simplify tool registry"
git commit -m "test: add tool execution tests"
git commit -m "chore: update dependencies"

# 提交并显示修改内容
git commit -v

# 修正最后一次提交
git commit --amend
```

### 3.3 Pull Request

```bash
# 创建 PR（需要 GitHub CLI）
gh pr create --title "feat: add new tool" --body "## Summary\n\n## Test plan"

# 列出 PR
gh pr list

# 查看 PR 状态
gh pr status

# 合并 PR
gh pr merge

# 查看 PR
gh pr view 123
```

## 4. 调试命令

### 4.1 日志输出

```bash
# 启用 verbose 日志
claude --verbose

# 输出到文件
claude --log-file /path/to/log.txt

# 设置日志级别
export LOG_LEVEL=debug
claude
```

### 4.2 性能分析

```bash
# 启用性能分析
export ENABLE_PROFILING=true
claude

# 生成火焰图（如果可用）
claude --profile
```

### 4.3 内存调试

```bash
# 启动时生成堆快照
claude --heap-snapshot

# 监控内存使用
claude --memory-monitor
```

## 6. 文件操作

### 6.1 常用工具命令

```bash
# 查找文件
find . -name "*.ts" -type f

# 查找包含关键词的文件
grep -r "toolExecution" src/

# 统计代码行数
wc -l src/**/*.ts

# 查看文件变更
git diff src/tools.ts
```

### 6.2 路径相关

```bash
# 获取当前目录
pwd

# 切换目录
cd src/services/tools

# 列出目录内容
ls -la

# 查看文件详情
stat src/main.tsx
```

## 7. Docker 与容器

### 7.1 构建与运行

```bash
# 构建镜像
docker build -t claude-code .

# 运行容器
docker run -it claude-code

# 带卷挂载运行
docker run -it -v $(pwd):/app claude-code
```

### 7.2 开发容器

```bash
# 启动开发环境
docker-compose up dev

# 停止容器
docker-compose down

# 查看日志
docker-compose logs -f
```

## 10. 环境变量速查

| 变量 | 说明 | 示例 |
|------|------|------|
| `ANTHROPIC_API_KEY` | Anthropic API 密钥 | `sk-xxx...` |
| `LOG_LEVEL` | 日志级别 | `debug`, `info`, `warn`, `error` |
| `DEBUG` | 调试模式 | `true` / `false` |
| `NODE_ENV` | 运行环境 | `development`, `production` |
| `CLAUDE_CODE_CONFIG` | 配置文件路径 | `/path/to/config.json` |
| `CLAUDE_CODE_DATA_DIR` | 数据目录 | `~/.claude` |
| `HTTP_PROXY` | HTTP 代理 | `http://proxy:8080` |
| `HTTPS_PROXY` | HTTPS 代理 | `http://proxy:8080` |

## 11. 常见错误代码

| 代码 | 含义 | 解决方法 |
|------|------|----------|
| `EACCES` | 权限拒绝 | 检查文件权限 |
| `ENOENT` | 文件不存在 | 检查路径是否正确 |
| `ECONNREFUSED` | 连接被拒绝 | 检查服务是否运行 |
| `ETIMEDOUT` | 连接超时 | 检查网络连接 |
| `ENOMEM` | 内存不足 | 增加可用内存 |
| `EBUSY` | 文件被占用 | 关闭占用进程 |

## 12. 快速参考卡片

### 开发流程
```
1. git checkout -b feature/xxx
2. npm run dev
3. 修改代码
4. npm test
5. git add . && git commit -m "feat: xxx"
6. git push origin feature/xxx
7. gh pr create
```

### 调试流程
```
1. claude --verbose
2. 复现问题
3. 查看日志
4. 添加断点
5. 分析调用链
6. 修复并测试
```
