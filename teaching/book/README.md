# 跟着消息走：Claude Code 源码的旅程

> 从你按下回车的那一刻起，你的消息将穿越一个完整的系统。
> 本书带你跟着它走完这段旅程。

## 关于本书

一本以《网络是怎么连接的》风格写的源码分析书。不按模块组织，而是跟着一条消息穿越 Claude Code 的每一层。

本书合并了模块化教学版和叙事版的最优内容，覆盖更完整、门槛更低。

## 六卷结构

| 卷 | 书名 | 读完你能做什么 |
|---|------|-------------|
| 卷零 | 出发前的地图 | 理解 Claude Code 和 Agentic Loop |
| 卷一 | 消息的旅程 | 追踪请求流程、定位 bug、修小问题 |
| 卷二 | 引擎室的秘密 | 理解设计模式、读懂任意模块 |
| 卷三 | 造物主的工坊 | 独立添加新功能、写测试、提 PR |
| 卷四 | 架构师的棋盘 | 参与架构讨论、理解设计权衡 |
| 卷五 | Agent 的造物法则 | 独立实现 Anthropic 协议栈、构建自己的 Agent 框架 |

## 阅读前提

- 你会用终端（命令行）
- 你写过代码（任何语言都行）
- 你不需要懂 TypeScript（需要时会解释）

## 阅读路径

### 线性阅读（推荐新手）

卷零 → 卷一 → 卷二 → 卷三 → 卷四 → 卷五。每卷都依赖前卷的基础，不建议跳卷。

### 按需跳读（有经验的读者）

| 你的目标 | 从哪开始 | 跳读哪些 |
|---------|---------|---------|
| 快速了解 Claude Code 架构 | 卷一下半 (ch12) | 看旅程复盘全景图 |
| 理解某个具体模块 | 卷二对应章节 | 每章独立可读 |
| 动手写新功能 | 卷三 | ch29（工坊搭建）→ 目标章节 |
| 理解设计决策 | 卷四 | 每章独立，按标题选读 |
| 自己实现 Agent 框架 | 卷五 | 线性，组件有依赖 |

### 章节依赖关系

```
卷零（ch01-02）      无依赖，纯概念入门
  ↓
卷一（ch03-16）      依赖卷零的 Agentic Loop 概念
  │                  内部：ch04→ch05→ch06→...→ch15 链式依赖
  ↓                  ch16 是综合实战章
卷二（ch17-28）      依赖卷一的追踪经验
  │                  各章基本独立（ch18 需 ch17 目录基础）
  ↓
卷三（ch29-40）      依赖卷二的设计模式理解
  │                  ch29（工坊）是入口，ch30-39 可跳读
  ↓                  ch40 是综合实战章
卷四（ch41-52）      依赖卷一~三的源码知识
  │                  各章独立，按标题选读
  ↓
卷五（ch53-66）      依赖卷四的设计权衡分析 + 附录F 概念定义
                    内部强依赖：ch53→54→55→56→...→66 链式
                    ch66 将前 13 章的所有组件组装为完整框架
```

### 卷边界过渡

- **卷一结尾 (ch16)**：旅程复盘 + 引向"拆开每个齿轮"
- **卷二开头 (ch17)**：重申"你已在卷一中走完一次调用"
- **卷三开头 (ch29)**：强调"现在从读源码变为写源码"
- **卷四开头 (ch41)**：强调"从'怎么实现'转向'为什么这样实现'"
- **卷五开头 (ch53)**：强调"不再分析别人的代码，从零构建自己的框架"

### Git 版本锁定

```bash

# 查看最新书籍提交对应的源码快照
```
