# 《从零构建 AI 助手：Claude Code 源码解析与实战》

## 书籍定位

- **目标读者**：零基础开发者（会基本编程概念即可）
- **学习路径**：从 TypeScript 基础 → 构建简易 CLI 工具 → 理解 Claude Code 架构 → 参与开源贡献
- **核心价值**：不只是读懂源码，而是学会构建类似系统并贡献社区

## 各阶段详细规划

### 第一阶段：准备篇（P1-P4）

**目标**：让零基础开发者准备好学习后续内容

#### P1-TypeScript入门（约3万字）
- 从 JavaScript 过渡到 TypeScript
- 类型系统基础：基本类型、接口、泛型
- 常用工具类型（Partial、Required、Pick、Omit）
- 异步编程：Promise、async/await
- 模块系统：import/export
- 实战：编写一个类型安全的工具函数库

#### P2-Node.js与Bun入门（约2万字）
- Node.js/Bun 简介与安装
- npm/yarn/pnpm 包管理器
- CommonJS vs ESM
- 文件系统操作
- 网络请求（fetch）
- 实战：创建一个简单的 HTTP 服务

#### P3-命令行开发基础（约2万字）
- 命令行参数解析（commander.js、yargs）
- 输入输出处理
- 环境变量
- 进程管理
- 实战：构建一个带参数的 CLI 工具

#### P4-React基础速成（约2万字）
- JSX 语法
- 组件与 Props
- State 与 Hooks
- 实战：用 React 写一个简单的待办列表

**阶段产出**：学员能独立构建一个带参数解析和基本交互的 CLI 工具

- 实现 Shell 执行工具
- 工具注册表
- 实战项目：为 hello-world 添加文件操作工具

#### 03-接入AI API（约2万字）
- Anthropic API 简介
- 流式响应处理
- 构建 System Prompt
- 处理工具调用循环
- 实战项目：为 hello-world 添加 AI 对话功能

#### 04-添加交互界面（约1.5万字）
- Ink 框架简介
- 实现 REPL 界面
- 消息渲染
- 用户输入处理
- 实战项目：为 hello-world 添加彩色终端界面

**阶段产出**：学员拥有一个功能完备的"迷你 Claude Code"

## 教学特色

### 每章必备元素
1. **学习目标** - 本章结束时你能做到什么
2. **前置知识** - 需要哪些预备知识
3. **代码示例** - 完整可运行的代码
4. **实战练习** - 动手构建
5. **原理解析** - 为什么这样设计
6. **进阶挑战** - 学有余裕时的额外挑战
7. **与我们的小项目对比** - 对应到 Part 2 的迷你 Claude Code

### 跨章节项目
- Part 2 的"迷你 Claude Code"贯穿全程
- 每个概念都会回来改进这个项目
- 最终项目有完整的工具调用、AI 对话、权限控制、UI 界面
