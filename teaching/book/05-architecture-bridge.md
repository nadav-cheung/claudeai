# 05 - 从 Mini-Claude 到 Claude Code

> **本章目标**：理解 Mini-Claude 与 Claude Code 的架构差距，为深入学习 Claude Code 源码做好铺垫。

## 1. 回顾：Mini-Claude 的架构

我们构建的 Mini-Claude 具有以下架构：

```text
┌─────────────────────────────────────────┐
│              Mini-Claude                 │
├─────────────────────────────────────────┤
│                                         │
│  ┌─────────┐    ┌──────────────────┐    │
│  │ CLI     │───▶│ Command Router   │    │
│  │ (Commander)  │ (chat/status/...) │    │
│  └─────────┘    └────────┬─────────┘    │
│                          │               │
│                          ▼               │
│                 ┌──────────────────┐     │
│                 │   Tool Registry  │     │
│                 │  (read/write/shell) │    │
│                 └────────┬─────────┘     │
│                          │               │
│                          ▼               │
│                 ┌──────────────────┐     │
│                 │  ChatService     │     │
│                 │  (API 调用)       │     │
│                 └──────────────────┘     │
│                          │               │
│                          ▼               │
│                 ┌──────────────────┐     │
│                 │   REPL UI        │     │
│                 │   (Ink)          │     │
│                 └──────────────────┘     │
│                                         │
└─────────────────────────────────────────┘
```

**Mini-Claude 的特点**：
- 单文件架构（~200行）
- 直接 API 调用
- 简单工具注册表
- 基础 REPL 界面

## 3. 核心差距分析

### 3.1 工具系统

| 方面 | Mini-Claude | Claude Code |
|------|-------------|-------------|
| 工具数量 | 3 个 | 30+ 个 |
| 工具定义 | 简单 class | 完整 Tool 接口 + Schema |
| 工具注册 | 硬编码 | 动态注册 + Feature Flag |
| 参数校验 | 手动 if 判断 | JSON Schema 自动校验 |
| 权限控制 | 无 | 细粒度权限钩子 |
| MCP 扩展 | 无 | 原生 MCP 协议支持 |

### 3.2 API 通信

| 方面 | Mini-Claude | Claude Code |
|------|-------------|-------------|
| API 调用 | fetch 直接调用 | 封装好的 ApiService |
| 流式处理 | 基础实现 | 完整 SSE + 事件解析 |
| 错误处理 | try/catch | 重试 + 指数退避 |
| 上下文管理 | messages 数组 | 完整上下文窗口 |
| 工具结果 | 字符串拼接 | 专门的 tool_result 类型 |

### 3.3 UI/交互

| 方面 | Mini-Claude | Claude Code |
|------|-------------|-------------|
| 界面框架 | Ink 基础 | Ink 多栏布局 |
| 状态管理 | useState | React Context + Signal |
| 键盘处理 | TextInput | 自定义光标管理 |
| 快捷键 | 无 | Ctrl+C/L/Z 等 |
| 多会话 | 无 | Session 管理 |

### 3.4 安全与权限

| 方面 | Mini-Claude | Claude Code |
|------|-------------|-------------|
| Shell 执行 | 直接 exec | 沙箱隔离 |
| 文件操作 | 无限制 | 权限确认 |
| 工具白名单 | 无 | 基于项目的工具配置 |
| 网络请求 | 无限制 | 可配置的 MCP 服务器 |

## 4. 架构映射：Mini-Claude → Claude Code

| ChatService | services/api/claude.ts | `src/services/api/claude.ts` |
| REPL | screens/REPL.tsx | `src/screens/REPL.tsx` |
| CLI 入口 | main.tsx | `src/main.tsx` |

### 练习 2：添加新层到 Mini-Claude

**目标**：为 Mini-Claude 添加"日志层"

**提示**：
- 创建 `src/logging/` 目录
- 实现 `Logger` 类
- 在各层中集成日志

**答案要点**：
```typescript
// src/logging/logger.ts
export class Logger {
  private level: LogLevel;

  constructor(level: LogLevel = LogLevel.INFO) {
    this.level = level;
  }

  log(level: LogLevel, message: string, data?: unknown) {
    if (level >= this.level) {
      console.log(`[${level}] ${message}`, data || '');
    }
  }
}

export const logger = new Logger();
```
