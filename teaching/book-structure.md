# Claude Code 源码解析 - 书籍结构

> **本文档目标**：将 teaching 目录下的 28 个文档重构为一本书《Claude Code 源码解析》，包含面向不同读者群体的学习路径设计。

---

## 1. 书籍信息

| 项目 | 内容 |
|------|------|
| 书名 | Claude Code 源码解析 |
| 副标题 | 从架构设计到实战技巧 |
| 目标读者 | 有编程基础的开发者（会任一语言即可） |
| 特色 | Java/TypeScript 架构对比，帮助不同背景开发者理解 |
| 总章节 | 13 章正文 + 12 附录 + 3 实战章节 |
| 预计篇幅 | 约 600KB |

---

## 2. 整体结构

```text
第一部分：入门
├── 引言：如何阅读本书
├── 第 00 章：全局架构总览
└── 第 01 章：入口与启动流程

第二部分：核心系统
├── 第 02 章：终端 UI 框架 (Ink)
├── 第 03 章：工具系统
├── 第 04 章：工具执行与安全
└── 第 05 章：权限系统

第三部分：进阶主题
├── 第 06 章：上下文管理与压缩
├── 第 07 章：MCP 协议集成
├── 第 08 章：Agent 与多 Agent 协作
├── 第 09 章：记忆与持久化
└── 第 10 章：Skills 与插件系统

第四部分：通信与扩展
├── 第 11 章：API 通信与远程
└── 第 12 章：TypeScript vs Java 实战对比

第五部分：附录（源码详解）
├── 附录 A01-A11：各模块源码详解
└── 附录 A13：TypeScript 实战技巧
```text

## 4. 学习路径设计

### 路径 A：零基础开发者（从零构建）

```text
第 00 章 → 第 01 章 → 第 02 章 → 第 03 章 → 第 04 章 → 第 05 章
    ↓          ↓          ↓          ↓          ↓          ↓
 架构概览    启动流程    UI 框架    工具系统    工具执行    权限系统

 → 第 06 章 → 第 07 章 → 第 08 章 → 第 09 章 → 第 10 章 → 第 11 章
     ↓          ↓          ↓          ↓          ↓          ↓
   上下文      MCP 集成    Agent 协作   记忆系统    Skills      API 通信

 → 第 12 章 → 附录 A13 → 附录 A01-A11
     ↓          ↓            ↓
 语言对比    TypeScript   源码详解
           实战技巧
```text

### 路径 B：Java 开发者（架构对比）

```text
第 00 章 → quick-start.md（Java 开发者速览）
    ↓
第 01-05 章（对照 Java Spring 框架理解）
    ↓
第 06-11 章（对照 Java 生态理解）
    ↓
第 12 章（TypeScript vs Java 深度对比）
    ↓
附录 A01-A11（源码对照 Spring 源码理解）
```text

### 路径 C：专家路线（按需查阅）

```text
├── 需要什么查什么
├── 附录 A01-A11 为主要参考
└── 第 00 章作为索引入口
```text
