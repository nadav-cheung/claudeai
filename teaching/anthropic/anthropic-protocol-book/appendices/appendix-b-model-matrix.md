### 决策规则总结

| 规则 | 条件 | 推荐模型 | 优化策略 |
|------|------|---------|---------|
| 1 | 复杂推理（SWE-bench 级、数学证明、法律分析） | **Opus 4.7** | Prompt Caching 控制成本 |
| 2 | 长上下文（>200K tokens 文档分析） | **Sonnet 4.6** | 1M 上下文窗口 |
| 3 | 实时/高吞吐（聊天机器人、代码补全） | **Haiku 4.5** | 低延迟 + 低成本 |
| 4 | 批量/离线（数据标注、报告生成） | **Sonnet 4.6** 或 **Haiku 4.5** | Batch API 50% 折扣 |
| 5 | 通用生产（客服、内容生成、标准问答） | **Sonnet 4.6** | Prompt Caching + 模型路由 |

## B.6 模型 ID 命名规范

| 格式 | 示例 | 说明 |
|------|------|------|
| **无日期别名** | `claude-opus-4-7`, `claude-sonnet-4-6` | 4.6 代起使用。指向最新兼容快照，推荐生产环境使用 |
| **带日期快照** | `claude-haiku-4-5-20251001` | 固定快照，行为不变。用于需要版本锁定的场景 |
| **经典模型 ID** | `claude-3-5-sonnet-20241022` | 3 系列模型使用日期版本标识 |

> **建议**：生产代码中使用无日期 ID，自动指向最新兼容快照。评测和基准测试中使用带日期快照以保证可复现性。
